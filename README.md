# Hermed Bots

App macOS native pour piloter des bots Hermes. PRD et spec : `docs/prd/`. Règles agents : `AGENTS.md`.

La passe pull request exécute les tests fonctionnels. Les sondes de performance se lancent à part, voir `docs/perf-probes.md`.

## Installer

```bash
brew install --cask eliasprunaire/tap/hermed-bots
```

La mise à jour, la désinstallation et les preuves sont dans `docs/distribution.md`.
